# v1.2.0 安全性・異常処理レビュー

**対象**：Kiseki Storage v1.2.0 のソースコード（静的検査）
**確認日**：2026-10-13
**制限**：この環境にはWindowsおよびCargoがないため、実機・ビルド・実行時安全性テストは未実施。以下は実装内容および残るリスクの整理です。安全性を保証するものではありません。

## 対策した箇所

| 対象 | 対策 | 確認ポイント |
|---|---|---|
| egui E0599 | egui 0.32.3で使えない`ctx.content_rect()`を削除。既存パネルが各々不透明な背景を描画 | Windowsでコンパイル、パネル境界の表示 |
| フォント | Zen Maru Gothic Regular/Boldを埋込み、Windowsフォントパスへの読み込み依存を除去 | 日本語・記号表示、OFLライセンス同梱 |
| Windows Explorer | PATH内の`explorer.exe`ではなく、`GetWindowsDirectoryW`から絶対パスを作成 | 想定外の実行ファイルへの差し替え防止 |
| ファイルパス | shellやcmdを使わず `Command::arg(Path)`で引数を区切る | 意図しないシェル展開の防止 |
| ドライブ起動 | フォルダーの存在確認と起動エラーの案内を統一 | 存在しない/切断したドライブ |
| UI応答 | 開く操作はGUIと別のスレッド、連続クリックを600ms抑制 | ネットワークドライブ遅延でのUI応答 |
| ドライブ照会 | 論理ドライブ列挙APIが0なら全ドライブを無差別に問い合わせない | API失敗・未マウントドライブ |
| 異常終了 | 監視スレッドの通信切断時に状況を表示 | 監視スレッド停止 |
| 画像読み込み | アイコン画像のデコード失敗を即時パニックにしない | 破損アセット（ビルド成果物） |
| Webリンク | URLはプログラムに固定（`https://drive.c2s.me`）、ユーザー入力をコマンド化しない | デフォルトブラウザの起動先 |

## 残るリスク・公開前に確認が必要な事項

1. **管理者権限**：UACマニフェストの`requireAdministrator`はユーザー指定の仕様です。参照・表示が主用途のアプリとしては権限が高く、外部ブラウザや同期ソフト等を起動する際に昇格状態が継承される可能性があります。利用者へ明示し、可能なら通常権限化を検討してください。
2. **外部プログラム・OS**：Windows Explorer・既定ブラウザ・レジストリ・Win32 APIの実機上の振る舞いは未検証です。環境依存の失敗やOS設定の影響があります。
3. **ネットワーク接続**：ネットワークドライブのディスク情報照会は監視スレッド内で行いますが、OS APIが長く待つと次回の容量更新が遅れる可能性があります。アプリの終了処理はOSに依存します。
4. **スレッド数**：連打を抑制していますが、ユーザーが連続して切断ドライブを開くと複数の待機スレッドができ得ます。必要なら同時実行数制限またはタイムアウトを追加してください。
5. **外部依存**：crates.io依存関係の脆弱性検索とライセンス確認（`cargo audit`等）は未実行です。`Cargo.lock`を作成・コミットしてから実施してください。
6. **画像・商標**：アバターや用途別ICO、各社のロゴのGitHub再配布条件が未確認です。公開前の素材権利確認が必要です。
7. **プライバシー**：画面にはユーザー名・デバイス名・CPU等が表示されます。スクリーンショットや動画を公開する前に個人情報をマスクしてください。
8. **監視可能範囲**：表示対象はC:～Z:の論理ドライブです。全ディスクの詳細なパーティション構造、マウントポイントのみのボリューム、SMART等を列挙するツールではありません。

## 実機での確認推奨

`cargo build --release`、`cargo test`、`cargo clippy --all-targets -- -D warnings`を実行し、UAC、通常の固定ドライブ、RAMDisk、未接続ドライブ、クラウド、2K以上の高DPI画面、日本語表示を確認してください。


## v1.2.0 追加機能の確認事項

- SNSとブランドサイトへのリンクは、ソース内に固定した `https://` URL のみです。ボリューム名、任意のファイル名、ユーザー入力からURLを組み立てません。
- 外部URLは既定ブラウザに委譲し、`cmd.exe` やPowerShellのコマンド文字列を生成しません。
- パーティションのグループ判定はボリュームラベルに基づく画面表示だけで、実際のファイルの移動・削除・分類保存を実行しません。
- 中央一覧はC:～Z:のWindows論理ドライブです。NTFSのジャンクションやドライブ文字のないボリュームを列挙するものではありません。
- README等に個人的な保管先の実名・健康記録・職歴・住所・金融口座の細目を収録していません。
- Windows向けRustビルドと実機のUI・権限動作はこの作成環境では未検証です。公開前にビルド、テスト、GUI動作確認を行ってください。
