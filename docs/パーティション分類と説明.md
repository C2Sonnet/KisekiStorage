# Kiseki Storage — パーティション分類と説明

本資料はv1.2.0の分類定義です。ボリューム名に分類名が含まれる場合のみアイコン・説明・タグを自動設定します。ドライブ文字の割当は固定しません。実際のファイル内容の検査・移動はしません。

名前に `C2S｜`、`C2S|`、`C2S│` を含む場合は `Local` バッジを付けます。`C2S｜システム` は `システム` として表示します。アイコン名はドライブ文字に依存しません。

ドライブ文字がなくWindowsが論理ドライブとして割り当てていない領域、またはA:・B:は中央一覧の検出対象外です。中央一覧ではC:～Z:を検索します。

プライバシー保護のため、READMEおよび本資料には具体的な勤務先・住所・医療記録・銀行口座等の実名サブフォルダを収録しません。
