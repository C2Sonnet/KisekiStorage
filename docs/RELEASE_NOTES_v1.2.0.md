# Kiseki Storage v1.2.1 — Release Notes

**キセキの倉庫** のパーティション分類と操作性を改善したバージョンです。

## 更新内容

- 最新のパステル調パーティションアイコン13種類（768×768 PNG）へ一新しました。
- ボリューム名から用途を識別する方式を維持し、ドライブ文字に依存しない分類に対応しました。
- 共通・生活相関・作業相関・仕事相関・アーカイブの各グループと、未分類欄を追加しました。
- C:～Z:の論理ドライブを対象とし、N:・O:などのドライブも表示対象に加えました。
- アプリ起動時にウィンドウを中央配置するようにしました。
- System Overviewの情報行を少し拡大しました。
- 13分類の説明文・最大5タグを新しい用途定義に合わせて更新しました。
- クイックアクセスの文字・ボタン高さを少し小さくしました。
- 2つのアバターとブランド名にホバー発光とクリック操作を追加しました。
- ヘッダーの英語装飾ラベルを削除し、10種類のSNSアイコンリンクへ置き換えました。

### 表示方法
- `C2S｜システム` はどのドライブ文字でも「システム」のアイコン・説明・タグを適用し、`Local` バッジを表示します。
- 分類できないラベルは「未分類」に表示します。

### 利用上の注意
- Windows 10/11向け。起動時に管理者権限を要求します。
- 本ZIPはソースコードです。Windowsでのビルドと実機表示は未検証です。
- システム情報に機器名・利用者情報が表示されます。スクリーンショット公開時はプライバシーにご注意ください。
