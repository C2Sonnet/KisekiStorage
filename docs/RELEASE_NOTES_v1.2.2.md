# Kiseki Storage v1.2.2 リリースノート

「仕事」などのパーティションアイコンが空白になる不具合を修正したメンテナンスリリースです。

- 破損していた「仕事.png」を含む13分類すべてのアイコンを、ご提供のICOから変換したPNGへ交換しました。
- PNG画像のデコード検査を実施し、Rustの回帰テストを追加しました。
- 読み込みに失敗した場合は、空白ではなく代替表示とエラー記録を行います。
- ソースZIPの日本語ファイル名の文字化けを修正しました。
- 元のICOは `assets/partition_ico_source/` に収録しています。

プログラムのレイアウト・グループ分け・SNSボタン・既存機能は変更していません。

**検証状況：** アイコン素材・ZIP・ソース参照の静的検査は完了。Windows上のビルド・表示テストは未実施です。
