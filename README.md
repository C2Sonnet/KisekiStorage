## キセキの倉庫について

たくさんのファイルに囲まれた日々を、少し分かりやすく、少し心地よく。

**Kiseki Storage** は、Windowsのストレージ状況を一つの画面にまとめる小さなダッシュボードです。やわらかな暖色系のデザインと、用途別のアイコンで、普段使うドライブの場所と空き容量を見渡せます。

## できること

- **ストレージ一覧** — C:～M:の対象ドライブをカード形式で表示。容量・使用率・空き容量を確認できます。
- **わかりやすい分類** — 「システム」「アプリ」「データ」「制作」「開発」など11種類の分類に応じたアイコン・説明・タグを表示します。
- **ワンクリックで移動** — ドライブカードを一度クリックすると、エクスプローラーでそのドライブを開けます。
- **パソコンの概要** — Windows情報、CPU、RAM、ストレージ合計などを確認できます。
- **クイックアクセス** — RAMDisk、SSDCache、OneDrive、Google Drive、C2SDriveへアクセスできます。
- **自動更新** — RAMは約10秒ごと、ディスク容量は約30秒ごとに表示を更新します。

## ご利用環境

**Windows 10 / Windows 11 向け**。起動時にWindowsのユーザーアカウント制御（UAC）が表示され、**管理者権限**を求めます。

アプリ画面では、上部にコンピューターの概要、中央にドライブ一覧、下部に5つのクイックアクセスを配置。中央の一覧だけを上下にスクロールできます。

## 使い方

1. ビルド済みの `kiseki-storage.exe` を実行し、UACを確認してください。
2. 中央のカードから使用量やパーティションの役割を確認します。
3. 開きたいドライブのカードをクリックします。
4. 画面下部のボタンから指定フォルダーやクラウドサービスを開くこともできます。

> **ご注意**  本リポジトリにはWindows用のビルド済みEXEを同梱していません。ソースコードからのビルド方法は [ビルド案内](docs/BUILDING.md) をご覧ください。

## ご利用上の注意

- C:～M:以外のドライブは中央の一覧には表示しません。A:、B:、Z:はクイックアクセスに割り当てられています。
- 接続されていないドライブや、利用できない同期フォルダーは開けません。
- 表示する容量はWindowsから取得した値です。アクセス制限やドライブの状態により取得できない場合があります。
- アプリ自体は、ドライブの容量情報を参照します。カードを開く操作はWindowsエクスプローラーに引き渡します。
- C2SDriveボタンはブラウザーで外部サイト（`https://drive.c2s.me`）を開きます。
- 本ソフトウェアには保証がありません。重要なデータは別途バックアップしてください。
